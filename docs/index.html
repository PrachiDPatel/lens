Lens

Show, don't screenshot.

What it is

Lens is a small floating assistant that lives in Chrome and VS Code. When you ask an AI a question, it automatically captures the relevant context — a screenshot, the page text, and console errors in the browser; your file or selection, problems, and open files in the editor — and sends it along with your question. No manual screenshots, no copy-paste loop.

Download

Chrome extension (.zip) VS Code extension (.vsix) install.ps1 install.sh SHA256 checksums

Downloads live in the repo under downloads/, versioned per release. Prefer the scripts? They're plain text — read them before you run them.

Install — Chrome

  1. Download lens-chrome.zip and unzip it somewhere permanent.
  2. Open chrome://extensions, turn on Developer mode.
  3. Click Load unpacked and select the unzipped folder.
  4. Press Alt+L (⌘⇧L on Mac) on any page. Opening the panel with the shortcut is what grants the one-time permission screenshots need.

Install — VS Code

With the .vsix downloaded:

code --install-extension lens-vscode.vsix

Or run the install script, which downloads and installs it for you:

# Windows (PowerShell)
.\install.ps1

# macOS / Linux
bash install.sh

Security notes

  • The install scripts are plain text. Open them and read every line before running — they only download release files from this repo's releases page, nothing else.
  • Verify the downloads. Each release ships a SHA256SUMS file; check the hashes before installing.
  • Chrome installs are manual. Chrome doesn't allow silent extension installs — you load it yourself in chrome://extensions, so nothing can sneak in.
  • No admin rights needed. Everything installs into your own user folders.
  • Your API keys stay yours. In Chrome the key lives in the browser's local storage (not encrypted at rest — use a dedicated key you can rotate); in VS Code it lives in the OS keychain via SecretStorage. Keys are only ever sent to api.anthropic.com, only when you ask.
  • No backend, no accounts, no telemetry. Nothing phones home.
